## Getting Started

### v1 (plain HTML)
```bash
cd v1 && python3 -m http.server 8081
# → http://localhost:8081
```

### v2 (React)
```bash
cd v2 && npm install && npm run dev
# → http://localhost:5173
```

### Deploy

**v1 → GitHub Pages:** Push to `main` → auto-deployed at `https://minhquan-maker.github.io/myportfolio/v1/`
