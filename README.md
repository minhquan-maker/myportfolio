## Getting Started

### Preview locally

```bash
cd web-V1
python3 -m http.server 8080
# → Open http://localhost:8080
```

### Deploy to GitHub Pages

Push to the `main` branch → automatically deployed at:

```
https://minhquan-maker.github.io/myportfolio/v1/
```
